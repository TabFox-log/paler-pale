# paler-pale

## what is this?

this resource pack desaturates all the pale wood items to remove the pinkish hue they present.

## downloading

you can either click 'Code' > ['Download ZIP'](https://github.com/nyxion-luna/paler-pale/archive/refs/heads/main.zip) or you can go to the resource pack's [modrinth page](https://modrinth.com/resourcepack/paler) and download the right version for your game.
